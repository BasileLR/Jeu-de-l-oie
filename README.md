# VibeOie - Le Jardin des Oies Personnalisé

Bienvenue dans notre version personnalisée et interactive du **Jeu de l'Oie**, développée dans le cadre du TP de Vibe Coding.

## 🎯 Fonctionnalités du jeu
* **Sélection des équipes :** Jeu dynamique de 2 à 10 équipes.
* **Plateau interactif :** Affichage en temps réel de la position des pions sur le plateau.
* **Système de Cartes Actions (Style Mille Bornes) :** En plus des classiques cases du plateau, chaque joueur dispose d'un deck de cartes actions tactiques qu'il peut choisir d'utiliser à son tour (ex: *Avancer de force*, *Reculer un adversaire*, *Passer son tour protégé*).
* **Variantes de règles :** Intégration de pièges et de bonus inédits pour pimenter la partie.

## 🛠️ Conditions techniques
* **Langage :** HTML5, CSS3, JavaScript (Vanilla).
* **Exécution :** Totalement local, s'exécute directement dans n'importe quel navigateur web moderne (Chrome, Firefox, Edge) sans serveur requis.

## 🚀 Lancer le jeu
1. Clonez ce dépôt sur votre machine.
2. Ouvrez le fichier `index.html` (ou le fichier du jeu fourni) dans votre navigateur.
